### A1. `master_failed` on big pools — top priority, well-scoped

Symptom: on k30/k40 pools (~30k+ columns), all three HiGHS methods
(`highs-ds`, `highs-ipm`, `highs`) return solutions whose partition-row
residual exceeds `feasibility_tolerance` in
`src/master_lp_scipy.py::solve_restricted_master_lp` (check at the
"partition-infeasible" raise, ~line 318). We raised the default 1e-7 → 1e-6
(commit 2cc40d9) after seeing 1.26e-7; the 15 h resume STILL failed, so
residuals grow with pool size (likely BIG_M=5e5 / bus-cost=1e5 conditioning).

Diagnose first (cluster):
```bash
cd ~/EVSP-DR/src
grep -h "master failed" cg-bigtar_867*_*.out | sed 's/.*violation=//' | sort -g | tail -5
tail -8 cg-bigtar_867478_15.out
```

Fix in two parts (both in `src/exact_pricer_expanded.py` CG loop):
1. **Never lose the incumbent**: the loop already holds the last good `lp`
   (previous iteration). On `master_failed` AND on the final-LP re-solve
   failure, write that last good LP into the status JSON as `final_lp` with a
   field like `"final_lp_source": "last_good_iterate"` instead of null.
   A 15 h run must never end with a null deliverable.
2. **Stop failing on benign residuals**: preferred = scale-aware acceptance:
   compute the residual's objective impact (`violation × BIG_M_PENALTY`) and
   accept with a printed warning when that impact < 1.0 (i.e. violation
   < ~2e-6 at BIG_M 5e5), recording `max_row_violation` in the status JSON.
   Alternative: pass `feasibility_tolerance=1e-5` from the pricer only (the
   strict default stays for MIP-side uses). Do NOT silently loosen without
   recording the violation — honest labeling is a project rule.

After fixing: `sbatch --array=<failed indices> submit_cg_bigtariffs.sub`
(resume reloads journals in seconds; find indices via
`sacct -X -n -j 867334 --format=JobID,State | grep -v RUNNING`).

### A3. Per-cell best-verdict table (dedupe passes) and the 240-arm question

The orchestrator writes one output per pass (`_rrz_p1/2/3`), so raw counts
overstate open cells. The question that matters: **did GIRO-seed co-injection
(commit f4e31c3) move the g240 cells off 200–424 buses?** Get the deduped
current-best per cell:
```bash
cd ~/EVSP-DR/src && python3 - <<'PY'
import glob, json, re, collections
best = {}
for f in glob.glob("results/*/**_mip*rrz*.json") + glob.glob("results/*/*_mip*rrz*.json"):
    try: d = json.load(open(f))
    except Exception: continue
    b = d.get("buses")
    if not isinstance(b, int): continue
    cell = re.sub(r"_(match_mip_rrz_p\d|cheat_mip_rrz)\.json$", "", f.split("/")[-1])
    if cell not in best or b < best[cell][0]: best[cell] = (b, d.get("status_name"), f.split("/")[-1])
k_of = lambda n: int(re.search(r"_k(\d+)_", n).group(1))
rows = sorted((k_of(c), c, v) for c, v in best.items())
open_cells = [(k, c, v) for k, c, v in rows if v[0] > k]
print(f"{len(rows)-len(open_cells)} closed / {len(open_cells)} open (deduped)")
for k, c, v in open_cells: print(f"  k={k:<3} best={v[0]:<4} {v[1]:<11} {c}")
PY
```

## 5. Non-negotiable conventions

1. Never commit `results/`, generated CSVs, `__pycache__`, `grbnodes*`.
2. Honest labeling: `certified` (min_rc ≥ −ε) ≠ `stalled_marginal_returns` /
   wall-stopped (incumbents). Never upgrade a label.
3. Physics regimes are explicit everywhere: convention 300/300/0 vs realism
   240/220/res — never mix pools/covers/seeds across regimes without
   re-realization; `validate_injected_route` refuses, it does not warn.
4. All MIP on `scaglione`; CG resume-safe elsewhere.
5. Descriptive `#SBATCH -J` names; query with `sacct -X --name=<name> -S today`.
6. rrz caches: rerealized covers/seeds are cached next to their source
   (`*_rrz_g{G}*.json`); if a rerealize bug is fixed, purge stale caches:
   `find results -name '*_rrz_*.json' | xargs grep -l '"exception' | xargs -r rm -v`.
7. Commit style: what + why, `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`;
   push to `origin/peel-and-price` so the cluster can `git pull`.
