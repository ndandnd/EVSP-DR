# Primary-source literature review: EVSP–DR algorithmic acceleration

Date: 2026-09-12. This review focuses on ideas that fit a conference paper in about eight weeks. The integrated [review](REVIEW.md) and [work orders](WORK_ORDERS.md) set the implementation priorities; the papers below are resources, not a requirement to implement every method.

The evidence favors improving the current column-generation architecture. TOU-aware charging, partial charging, capacity rows, stabilization and integer diving already have substantial precedents. A paper therefore needs a validated method and useful controlled computational findings, rather than treating electricity-cost optimization alone as new. The recommendations below are project-specific inferences from the papers and inspected code. No published speedup is used as a forecast for EVSP–DR.

## Five transfers to screen

### 1. Efficient capacity-adjusted charging windows

Zhang et al.'s effective-cost window formulation is the closest mathematical reference; the table gives its equation anchors. The capacity branch already includes charger duals in window selection. The implementation opportunity is repeated evaluation, not adding missing dual terms.

Build a capacity-dual prefix array per station and iteration. Determine the occupied rows using the current conservative interval convention, then query their sum in O(1). Integrate TOU energy costs separately; never prorate a capacity-row penalty at a fractional endpoint. Prefix sums alone still require scanning the feasible start breakpoints. Avoided scans require an exact memo hit or a separately proved range-minimum algorithm. Memo keys must include every relevant physical window, station/power, tariff/grid, objective and dual identity. Clear dynamic results when duals change.

Preserve the exhaustive selector as an oracle, including its minimizing interval and tie rule. Compare per-arc costs, full-route reduced costs and global tiny-instance pricing minima before timing the saved hard k=3 dual. This is the first capacity implementation task; see WO-3.

### 2. Sparse candidate pricing with unrestricted fallback

The Parmentier paper and MIT implementation offer the strongest concrete starting point. For this project's event graph, construct a deterministic sparse candidate set using base cost, waiting, deadhead energy and successor feasibility, while preserving incumbent/support arcs. Every candidate must pass current-model replay and reduced-cost recomputation.

A failed sparse search triggers the unrestricted exact oracle. Only that oracle, under the current original master duals, may support the existing termination certificate. Record failed sparse rounds and their overhead. Tune sparsity on a subset of chains, freeze it, then measure total pricing time and exact-oracle calls on held-out cases. Implement only after removing demonstrated per-call overhead and screening the existing enrichment modes.

### 3. Adaptive dual smoothing

Pessoa et al. provide the main theoretical reference. In this project, smoothing is a separate experimental treatment: generate candidates using a convex combination of a reference and current dual vector, then recompute their reduced costs under the current unsmoothed vector. Relax smoothing after failure; always perform unrestricted pricing with current unsmoothed duals before certification.

Measure total calls and time, rather than assuming fewer iterations imply lower runtime. The existing duplicate-incidence fallback is different: its log claims an interior-point retry, but only the SciPy path changes method; production Gurobi currently does not. Correcting that message and testing an alternate RMP dual solve are separate tasks from introducing smoothing.

### 4. Better multi-column and integer-pool selection

Bärmann et al.'s thresholded enumeration is a useful reference if the existing sink-predecessor batch proves insufficient. That batch retains the global shortest path but does not enumerate true k-best paths. First benchmark the already implemented complementary selector and post-CG perturbed-dual diversification. Then, if needed, try bounded DAG path enumeration with completion bounds and retain the exact best route.

Select columns using the full master identity. Trip incidence is enough for the uncoupled baseline; capacity schedules and V2G profiles can distinguish otherwise identical trip sets. Measure time to a validated fleet incumbent and charging cost, pool size, MIP overhead and final certificate. Equal LP endpoints can coexist with different integer pool optima.

### 5. Reuse existing dive/peel prototypes only after a model audit

The de Vos and Sadykov diving references motivate residual pricing and bounded backtracking. The repository already contains `run_exact_dive.py` and `run_peel_and_price.py`; audit them before commissioning replacements. Their tariff, event graph, capacity, terminal-energy and replay assumptions must match the experiment.

Compare a frozen CG-pool MIP against one bounded dive or repair treatment at equal total budgets. Fixing routes is heuristic and may exclude useful combinations. Its validated incumbent, a finite-pool MIP proof and an unrestricted pricing certificate are different outcomes. Larger pools and deeper dives need not improve time to the target.

## Mathematical resources for Phase 1

Fleet-first optimization is particularly relevant when the immediate question is whether the GIRO fleet target can be reached or proved. Desaulniers' [large-fixed-cost paper](https://www.sciencedirect.com/science/article/pii/S0305054805002066) and the lexicographic paper in the table provide precedents. Farley's [early LP bound](https://pubsonline.informs.org/doi/10.1287/opre.38.5.922) and Desrosiers, Lübbecke, Desaulniers and Gauthier's [Branch-and-Price book](https://www.gerad.ca/en/papers/G-2024-36) support the bound-oriented perspective.

The [mathematical notes](MATHEMATICAL_NOTES.md) derive the unit-cost covering dual-scaling bound and identify the existing helper's partitioning/model-contract mismatch. Adapt that helper deliberately; a weighted RMP value or a heuristic pricing route is not a fleet-only certificate. Compare a rigorous lower bound with an incumbent feasible in the same named model, with conservative numerical rounding.

## Code reuse and deferred architectures

The verified MIT implementation is Parmentier's [ElectricalVSP-ColumnGeneration](https://github.com/axelparmentier/ElectricalVSP-ColumnGeneration), pinned in the table. Its C++17/CPLEX/Boost dependencies differ from the Python/Gurobi stack here. Inspect the column-generation controller, pricing and backward-bound code for patterns; preserve attribution and license notices if copying. It was inspected, not compiled or benchmarked in this review.

The Jacquillat/Lo repository has useful implementation examples, but no copying license was located at the checked commit. Treat it as an idea reference. “No public code located” for other papers is a bounded search result, not proof that authors cannot share an implementation.

Defer these larger changes unless the smaller experiments demonstrate a compelling need:

- Replacing the event/SOC DAG with a non-dominated charging multigraph and bidirectional labeler. The Parmentier and Desaulniers references are relevant, but TOU costs, charge-start fees, capacity duals and terminal policy require a fresh model-specific argument.
- Two-level subpath labeling or generic bucket-graph labeling. Their useful state structures differ from the present chronological DAG; benchmark instance characteristics before choosing either architecture.
- Full dynamic discretization discovery. He et al. supply a refinement framework for a different resource model. An optional tiny pessimistic/optimistic SOC pilot is reasonable, but its bounds must remain valid with tariff costs, occupancy and terminal energy. A conservative coarse-grid pricing result alone cannot certify omitted finer routes.
- Full branch-price-and-cut or stochastic/V2G integration as a prerequisite for this submission.

## A bounded experimental sequence

Follow the main review's two-week initial implementation budget: trustworthy telemetry, removal of unused Gurobi incidence construction, indexed warm replay and capacity-window evaluation. Correctness gates come before large runs. Screen existing enrichment first; choose sparse pricing or smoothing only if a measured gap remains. Do not run the Cartesian product of every idea.

For each retained method, compare its isolated change and then the useful combination against the frozen exact baseline. Hold input hashes, objective, master sense, tariff, SOC/time grids, capacity and terminal rules, initialization, hardware class and budgets fixed. Preserve failed and censored cases. Report cold/cache-hit build time, initialization, exclusive pricing/enrichment time, master work, peak RSS, exact minimum reduced cost, artificial total, LP objective, route weight, time to validated fleet target, charging cost and finite-pool MIP status.

Reserve the remaining time for held-out experiments, the final result grid, operational tariff/capacity sensitivities and writing. A credible research question is when joint duty/charging optimization beats a fixed-duty schedule whose charging has itself been fairly optimized under matched assumptions. Synthetic tariff peaks are useful controlled checks; they do not replace a fair comparator or establish novelty by themselves.

A certificate must name its discretized route space. Physical replay, an unrestricted LP pricing certificate, finite-pool integer proof and GIRO target attainment remain separate claims. The reviewed literature supplies methods to test; the eventual paper's efficiency and operational claims must come from matched EVSP–DR measurements.
