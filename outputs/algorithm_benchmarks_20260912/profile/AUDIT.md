# Independent benchmark audit

Read-only audit of `capacity/benchmark.py`, `replay/benchmark_replay.py`, their available results, and `master/benchmark_master.py`. Audit is of prototype correctness and timing scope, not a production acceptance certificate. Final capacity and replay benchmark-script hashes match their result JSON hashes (capacity `52ee4a9e262b433b49a0e8792487bdfc5ddb8133144e26f4010b22925c0e8635`; replay `8276b1ea763bc8ed19a50cc98d6d08ab3940c9492baaa4548df7871fb3ce6fc1`). Final master results were also inspected.

**Material correctness finding:** the capacity owner’s added independent master-row replay detects pricing reduced cost versus returned-record reduced cost differences of 0.12 and 4.8 on variable-tariff, station-power fixtures. The prototype reproduces the baseline exactly, and exhaustive enumeration of all 10 tiny-DAG paths agrees with pricing. Independent source inspection identifies the cause, corroborated by the owner’s eight-case baseline-only control matrix: `expanded_path_realization.py::realized_costs` passes global `mapping["charge_kw"]` into event tariff-block allocation, omitting station-specific power. With a 60 kW station and 240 kW global default, 60 kWh can be reassigned into 15 minutes instead of 60, changing the tariff split. This existing-source consistency failure is not introduced by the selector, but prevents a production-readiness claim. See `../capacity/extra_validation.json`. No production fix was attempted.

The material timing/reporting issue is replay setup: the warm replay ratio excludes an O(nodes + arcs) graph-index validation pass. The final real48/SOC2.5/lazy sample (4,225,616 arcs; 210 sequences) is **9.747× warm replay** (0.565551 to 0.058025 seconds), but **1.534× including index setup plus that warm batch** (index setup 0.310747 seconds). Adding common measured graph build to cold replay yields approximately **0.21% savings by arithmetic**, not a separately timed end-to-end run. Final reporting includes these distinctions. They must not be presented as CG or whole-job speedups.

Capacity: comparison uses the independent production selector, checks the full selected action as well as adjusted cost, and compares complete production network route records. This is useful differential validation; equal records alone are not an independent physical proof. Those added checks found the material existing-source cost inconsistency described above. The option ordering matches the production ordering; prefix cancellation/near ties fall back to the production row summation; the selected cost is recomputed using that sum. Boundary tests exercise the conservative occupancy predicate. No timing gain is credited to changing the objective or dropping route realization.

Capacity memo safety is conditional on its explicit contract: every pricing call invokes `begin_iteration`; duals are copied and the best-window memo is reset; a signature over events, prices, station/global power, grid, and start fee invalidates cached options. The caller must keep configuration fixed during the iteration. Direct calls with changed arguments after setup would violate that contract. Configuration and dual-change tests exist. Remaining scale questions include the full signature/prefix setup, cache memory growth, and hit rate on real pricing calls. The selector workloads and two-trip graph fixture are synthetic, although they call the actual production implementation. Tiny-fixture speedups cannot be extrapolated to the separate seven-hour capacity run.

Replay: only the outgoing-arc iterator is substituted; the original fixed-sequence dynamic program, lexicographic tie rule, and record realization remain intact. Validation asserts contiguous trip-node ranges and nondecreasing target order, allowing binary search to retain all matching arcs in source order, including duplicates. Exact equality checks cover full records and realized action traces for **1,980 sequence-case comparisons**, including feasible and rejected sequences. Reusing the source DP here is appropriate differential testing of traversal; it does not establish independent global optimality or physical correctness. Graphs come from synthetic fixtures and 12/48-trip subsets of a real input, with generated sequence workloads. They are not full operational CG runs. A changed or reloaded graph must rerun index preparation; the current immutable benchmark graphs satisfy that requirement.

Timing: both prototypes alternate reference/prototype order and retain raw repeated samples. Capacity includes begin-iteration setup inside the timed selector/network calls; graph build is separate. Replay separates cold and warm action/window caches, but always has a built graph and prepared index during timed replay; setup must be added or explicitly amortized. A shared timing lock covers measurements; the final replay harness also locks warmups to avoid contention with another owner's timed run. Correctness checks outside the lock can still create incidental background load; these remain local microbenchmarks, not isolated cluster performance trials. Superseded replay per-case filenames were removed and individual result files now include input hashes.

Master read-through: skipping incidence construction retains pool synchronization/validation; paired replay freezes pool additions and the cost rewrite. Checks compare primal values, duals, objectives and route weights, with a separate restricted-pool dual audit. Malformed route tests preserve the removed matrix's validation responsibility. The timing includes setup and its independent audit, excludes model close, and is correctly scoped to a synthetic master replay rather than CG. Synthetic routes contain no repeated trips, so the cheap nnz computation is valid for this benchmark; production integration must continue relying on synchronization to reject malformed pools. Final master replay results show **1.344× covering** and **1.287× partitioning**, with zero maximum paired numeric error. These are local synthetic master replays; full CG was not benchmarked.

Final hash and case-count checks pass. Preserve synthetic/subset and cache-regime labels, show replay setup costs beside traversal ratios, and retain the capacity cost-consistency failure. No production, cluster, register, Google Doc, or Slides edits were made by this audit.
