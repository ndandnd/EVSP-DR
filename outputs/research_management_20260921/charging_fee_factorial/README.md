## What the comparison establishes

Within each pair, trip sequences, recovered station paths, documented 18E1 charging physics, per-bus terminal-energy floors, shared capacity, tariff, solver budget and initialization are identical. This removes the trip-assignment confounding in the earlier fee-0-derived versus fee-5-derived figures. The three assignments remain separate conditions, not replications of one random experiment.

“Original” means the original trip assignment with recovered station paths. It is not the original recorded GIRO charging schedule. The existing model allows **one optional charge per fixed gap, confined to one tariff hour**. Station paths and trip assignment cannot change. Results concern this restricted fixed-path model, not fresh column generation or an unrestricted route/charging optimum.

Physics: 236.44 kWh initial energy and battery capacity, 15% reserve, 0.1 kW idle load, the documented 18E1 SOC-dependent opportunity taper, PARX 60 kW, minimum 3-minute active charge. Both fees use identical per-bus original terminal floors. Charger count 1 applies at 2190L and 4808 within this five-bus cohort. Static reference deadheads, no other 35 buses, platform/FIFO and crew constraints remain explicit limitations. Costs are synthetic tariff units, not observed invoices.

The reported electricity cost is **E = Σ(hourly tariff × charged kWh in that hour)**, integrating the SOC-dependent power curve and actual hour boundaries. The optimized objective is **F = E + fee × N**, where N counts activated charging connections. Thus fee 5 means five synthetic cost units per start. Fleet size is fixed at five, so this objective includes no fleet penalty. Reported solver bounds and relative gaps apply to F within this fixed-path charging model, not to a route-pool fleet problem. No charging-efficiency or monetary-currency conversion is added.

The paired table also derives a stronger start-count check from both objective bounds. Write electricity cost as E and starts as N, with solver lower bounds L0/L5 and feasible upper bounds U0/U5. Every optimum at fee 0 has N ≥ ceil((L5−U0−0.01)/5); every optimum at fee 5 has N ≤ floor((U5−L0+0.01)/5). A strict separation of those intervals establishes fewer starts at fee 5 for all optima of this restricted mathematical model, using Gurobi's bounds and a conservative 0.01 cost-unit numerical margin. It does not establish the displayed incumbent's particular start count as unique or optimal, and it is not an unrestricted routing claim.
