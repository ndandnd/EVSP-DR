# EVSP–DR experiment records

Start with [the experiment register](outputs/research_register/README.md) for the campaign index, filterable results, historical evidence and execution issues. The [Google Doc](https://docs.google.com/document/d/1hDSWYb2KG-8pnLFN9BdSKkbXOjhytm4bxQz_MsBw_BY/edit?tab=t.ts4vwph3s99i) contains the working interpretation and figures.

Use the [resource policy](outputs/research_register/RESOURCE_POLICY.md) before new launches: independent default-partition CG arrays default to 50 concurrent tasks unless a documented resource or policy constraint requires less. Always reserve scaglione-compute-01.

Keep original outputs immutable. Failed and superseded attempts remain visible with their status. Results from different physics, inputs, master senses or initialization policies are separate experiments. The generated register is a timestamped view of evidence, not a replacement for solver logs or saved columns.
