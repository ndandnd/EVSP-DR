# Independent finite-pool eight-bus checks

`verify.py` authenticates the three supplied files against the registered instance, owner summary and full decompressed post-dive SHA-256 values. Its `read_inputs` function checks the root prefix hash, post-dive length, trip indices, duplicate trips and all overlaps within each archived column. It reads trip IDs as CSV row positions, matching `build_problem`. No code extracts private schedules to these receipts.

`complement.py` and `complement.json` are the integer proof. The solver retains all distinct trip sets visiting a single eight-trip peak, a necessary condition for an eight-bus partition. It repeatedly picks an uncovered trip, queues every disjoint route covering that trip, and stops any branch with no remaining supporter for some required trip. At two remaining buses a lookup for the complement is sufficient. The negative result exhausts the tree. `check_small.py` and `small_fixtures.json` cross-check against direct brute force on 160 small synthetic pools including positive and negative controls.

`fractional.py` and `fractional.json` solve the trip-only fractional projection for all masks. The code reconstructs each equality and bound from the returned weights and route masks and records maximum residuals. `shared_plug_lp.py` is a separate LP which retains every eligible original record, its terminal-energy coefficient and its finite shared station-minute coefficients. Its receipt will record the solver status and, for an available solution, residuals recomputed directly from the source records. A numerical LP feasibility result has finite tolerance.

Run `python3 SCRIPT --instance SOURCE_CSV --journal POST_DIVE_JSONL_GZ --summary OWNER_SUMMARY_JSON --output RESULT_JSON` for `complement.py`, `fractional.py` or `shared_plug_lp.py`. Run `python3 check_small.py` for synthetic tests. Files named `mip.*`, `lp.json` and the optional script-mode routines in `verify.py` are exploratory and are excluded from the proof. An interrupted MIP cannot establish infeasibility.

The integer finding concerns exactly-once service with eight routes drawn from the frozen pool. Omitting plug constraints is a relaxation for proving that absence. It does not establish infeasibility for covering rows, a larger pool, or the full routing model. These proofs do not optimize charging or independently authenticate a chain of custody beyond the supplied, hash-bound source records.
